
# AI-Generated Website Showcase

## Goal

Create an AI-agent project that helps build a static website for showcasing the front pages of Next.js projects generated by AI models.

## Requirements

1. Host prompt Markdown files alongside the statically exported front page (`index.html`) of each corresponding AI-generated Next.js project and the supporting files needed to display it.
2. Organize results by prompt. Each prompt can have multiple generated front pages.
3. Assign each prompt project one or more tags describing its visual style, such as minimalist, modern, retro, or brutalist. Each generated front page inherits all tags from its prompt project and also has a tag identifying the AI model that generated it.
4. Provide a static index page where visitors can browse prompts and open their associated results.
5. Preserve each project's front-page appearance and client-side behavior in the static export, including the required CSS, JavaScript, images, fonts, and other supporting files.
6. Host only the exported front pages and their supporting files, not the full generated websites or project source code. No Next.js server or server-side runtime runs on the hosting site.
7. The name of the website is https://musepages.com

## Static Export Note

The `out` folder generated by `npm run build` was tested successfully when hosted on a remote machine. However, opening `index.html` directly from the local filesystem (`file://`) did not work.

Serve the exported files over HTTP or HTTPS, including for local previews, rather than double-clicking `index.html`. This requires only a static file server, not a Next.js runtime.

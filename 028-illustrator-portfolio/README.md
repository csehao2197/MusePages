# 028 — Maya Torres, illustrated worlds

A standalone Next.js illustrator portfolio **beside its original brief**, not inside a nested project. Only project028 is implemented here.

## Run and validate

The supplied workspace already provides ancestor `node_modules`. All used dependencies are declared locally; no install or workspace lockfile changes are needed.

```powershell
Set-Location 'C:\Code\Docs\sampe-md\nextjs-project-samples\028-illustrator-portfolio'
$env:NEXT_TELEMETRY_DISABLED='1'
npm run typecheck
npm run build
npm test
```

`build` runs `next build --webpack` with two build workers. `npm test` launches the **production** server at `http://127.0.0.1:3128`, refuses an existing server, and automatically shuts down its server process tree. Two browser workers; 35-second test, 60-second startup, and 240-second suite bounds. Do not separately start the server before running tests.

For manual preview, after building: `npm run start`. Stop it with Ctrl+C. Development: `npm run dev` (same port).

## Features and local behavior

- Moonlit botanical hero, sparse rose accents, three/two/one-column masonry, 18 typed fictional projects, six initially visible. Five work categories plus All; searchable collections.
- Native modal case studies with three views, composition/color process studies, hypothetical brief metadata, and commission handoff. Mobile touch swipe and explicit previous/next controls; native focus trap and Escape close.
- About, illustrated studio portrait, downloadable explicitly fictional CV, three service types, fictional testimonials with auto-drift and pause control.
- Four print previews: A3 base price; A2 adds $45 per print. Total is `(base + format premium) × integer quantity`. Quantity is limited to the fictional remaining edition count. Preview confirmation never creates an order or changes inventory.
- Commission estimate is `service base × 1–20 pieces × usage multiplier`: Editorial $800, Book $2,000, Brand $1,500, Personal/Other $600; single publication 1×, extended campaign 1.5×, exclusive rights 2×. These are illustrative estimates, not quotes or real rights grants.
- Inquiry native validation requires name, email, budget, future delivery date, message of at least 20 characters, and demo acknowledgement. A clearly labeled failure simulation exercises an actionable error and input-preserving recovery. Confirmation/reset are local.
- Theme state, forms and previews exist only in component memory. No backend, storage, analytics, real emails, accounts, credentials, checkout, payment, stock service, or live API.

## Adaptations, assets and transparency

The fictional illustrator, education, experience counts, client relationships, rates, edition counts, availability, and reviews are prominently labeled as concepts. Real brand names from the brief identify **hypothetical, uncommissioned briefs**, never endorsements. No awards or measured client results are claimed.

All artwork is original inline SVG/CSS made for this demo in `components/art.tsx` and the studio SVG in `app/page.tsx`. Twelve compositions include a botanical garden, artificial mind, coffee identity, migrating birds, city window, floating dream islands, herbarium, lost city, oat-field carton, deep-sea creatures, quantum orbits, and tea tins; six additional works explore alternate palettes/compositions. Carousel detail crops and color explorations are derived from those original compositions, not claimed as archival client process photographs.

No real artists' portfolios, downloaded images, external assets or generative-image services were used. The studio photograph requested by the brief is deliberately replaced with an original illustrated fictional portrait. Motion uses CSS studies, not externally hosted GIF/video. Testimonials use text roles, not real client logos.

Georgia/Times New Roman and Arial/Helvetica system stacks replace Playfair Display/Inter to avoid external-font/network build dependencies; no font files are copied or redistributed. Appearance depends on available system fonts. The wordmark uses italic Georgia; the Instagram control uses a generic camera icon rather than a brand logo.

Lucide icons come from the installed `lucide-react` package (ISC; some derived Feather icons are MIT). Both notices are retained in `public/lucide-LICENSE.txt`. Other framework/package licenses remain in their installed distributions. No third-party artwork licenses are required for the original compositions.

Social and email controls deliberately open explanatory local dialogs rather than link to unverified profiles/addresses. The source email is displayed as an unverified fictional contact. Privacy explains the actual memory-only behavior. “Download Full CV” downloads a small fictional text CV, not a purported real résumé.

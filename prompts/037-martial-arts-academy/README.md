# 037 — Iron Path Academy

A tailored Next.js discovery demo for the **fictional** Charlotte academy in `037-martial-arts-academy.md`. The application lives directly beside the brief; there is no nested project.

## Run and validate

Run these commands in PowerShell. Dependencies resolve from the existing ancestor `node_modules`; **no installation, root manifest change, or lockfile update is needed**.

```powershell
Set-Location 'C:\Code\Docs\sampe-md\nextjs-project-samples\037-martial-arts-academy'
$env:NEXT_TELEMETRY_DISABLED='1'
npm run typecheck
npm run build
npm test
```

`build` runs `next build --webpack` with **two build workers** configured in `next.config.ts`. `test` launches the actual production build on **127.0.0.1:3137**, waits for an HTTP response, runs Chromium desktop/mobile tests, and stops its owned server tree. Do not start another server before running tests: `reuseExistingServer: false` explicitly refuses reuse. Startup is bounded to 45 seconds, individual tests to 30 seconds, the suite to 180 seconds, with two workers and no retries.

To explore manually after a build:

```powershell
npm run start
# Open http://127.0.0.1:3137 and stop this server with Ctrl+C when finished.
```

Optional development command: `npm run dev`. These commands deliberately stay on the isolated project port.

## Scope and journeys

- Charcoal/red/gold identity, an original condensed system-font wordmark, cinematic illustrated academy hero, alternating section rhythms, and a fixed mobile trial bar.
- BJJ, Muay Thai, and MMA each have distinct introductory/experienced/youth class groups and detailed local panels, including supervised Sunday open mat.
- Typed fixtures are in `components\data.ts`. The fixed sample week is **November 2–8, 2026**, in **America/New_York / EST**. It does not roll forward with the current date or represent live availability.
- Trial selections are held **only in React memory**. One confirmation occupies one fictional session space; reset releases it. Reload clears all selections. No browser storage, account, network service, booking, email, or persistence backend exists.
- The intentionally exposed service-error checkbox exercises a deterministic local failure with no capacity change, followed by recovery.
- Membership “Start Training” buttons open a local enrollment **preview**, never enrollment. Single Discipline is $129/month; All Access is $169/month; Family is $249/month for two, plus $59 for each additional fictional member (2–6 members). `IRONPATH50` halves the total first month, including additions; following months remain full price. Four family members therefore preview **$183.50** first month and **$367.00** thereafter. Nothing is charged.
- Coaching biographies, community vignettes/event, six facility illustrations, academy journal, beginner resources, hours, location, and social-channel concepts all use functioning local panels or section links. The gallery starts paused, can auto-advance every five seconds while visible, pauses for manual controls, and cannot auto-play with reduced motion.

## Safety adaptations and mocks

The source's academy identity, disciplines, class names/times, price structure, section architecture, and broad youth band inform the design. Unsafe or unverifiable marketing details are deliberately adapted:

- No “#1” ranking, real ratings/reviews, competitive records, medals, real affiliations, certifications, awarded coaching ranks, student counts, promotion deadlines, endorsements, retention figures, or business outcomes.
- Brief-supplied coach names are explicitly **fictional personas**, with original abstract portraits and program roles rather than credential claims.
- Community quotations are labeled scripted vignettes, **not student testimonials**. No real students, children's portraits, body/health information, medical guarantees, or personal histories.
- Discovery and scheduling only: no combat/self-defense instruction, dangerous drills, training videos, or violence.
- The form substitutes a **synthetic visitor/guardian alias** for name/email/phone. Never enter a child's identity, contact data, health information, or any other personal details. The text input validates fictional-alias syntax; it cannot prove that an entered alias is fictional.
- The address, telephone, email, hours, facility, equipment, event, discount, capacities, and prices are illustrative concepts. Contact details are unlinked placeholders; the map is schematic, not navigation.
- No real enrollment, payment, cards, accounts, API, provider integration, credentials, messages, or backend.

All authored files and build/test output stayed inside this `037-martial-arts-academy` folder. No other project, ancestor package/lockfile, collection tracking file, commit, push, deployment, or provisioning was performed.

## Artwork, fonts, and notices

`public\academy.svg`, `public\spaces.svg`, the inline portraits/space SVGs, schematic map, and CSS wordmark/art direction are original artwork created for this demo. They simulate cinematic imagery; **there are no photographs or videos**. No stock images, copied academy assets, externally hosted assets, or external font requests are used.

Headings use locally available **Impact / Arial Narrow / Franklin Gothic Medium / sans-serif**, and body text **Arial / Helvetica / sans-serif**. Oswald and Inter from the brief are intentionally replaced by system fonts; no font binaries are distributed.

Interface icons come from `lucide-react` **1.61.0**, ISC-licensed with applicable Feather-derived MIT notices retained in `THIRD-PARTY-NOTICES.txt` and in the installed dependency. No Tailwind or Framer Motion dependency is used; styling and motion preferences are handled with authored CSS and React.

# 本轮 Agent 任务

## 目标

1. 网站中的 prompt 应在页面内的文字 codebox 中展示，而不是直接链接到原始 Markdown 文件。
2. 建立 `task/` 目录，用 `TASK.md` 保存本轮需要 Agent 完成的任务，用 `progress.log` 记录进度以便意外中断后恢复。
3. 将 `task/progress.log` 加入 Git 忽略规则，并更新相关工作规范。
4. 将原 `src/proj-gen.md` 的全部说明合并到根 README，修正链接并删除原文件。

## 验收要求

- 集合中的“Read prompt”打开静态展示页，codebox 保留原始文字与换行，不将 prompt 当作 HTML 执行。
- 当前示例生成流程及已有四个作品的 prompt 展示保持一致，桌面端和移动端均可阅读。
- Agent 开始或恢复任务前读取本文件和已有进度日志；关键步骤、验证结果、阻塞和下一步写入日志。
- 不执行生产构建或触发 Cloudflare 发布，不覆盖其他作品。

## 使用方式

用户在每轮任务前维护本文件，写明本轮目标、范围、限制和验收要求。Agent 不应擅自改写任务目标，也不应把进度记录混入本文件。

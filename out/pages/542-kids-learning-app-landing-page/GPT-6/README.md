## Implementation

Source: `out\pages\542-kids-learning-app-landing-page\GPT-6\`.
Public static resources: `out\`; final URL: `pages/kids-learning-app-landing-page/GPT-6/index.html`.

The user authorized a no-build HTML/CSS/browser-JavaScript adaptation, replacing the requested Vite/React/TypeScript runtime and `dist` build with direct static files in `out`. All content and complete lesson datasets are centralized in JavaScript-compatible `src\content.ts`, copied to browser `content.js` without compilation. Lucide icons are locally rendered SVG from the existing npm package; specified Latin fonts are self-hosted Fontsource files. Three exact supplied clay images are downloaded under `public\images` and exported to `out\images`. No placeholder artwork.

Features: shared three-age curriculum, two reading and two math exercises per age, individual word breakdowns, opt-in local-English-voice speech, specific hints, gentle success feedback and restart, sample dashboard periods/derived totals and proportions, monthly/yearly pricing, accessible in-memory routine dialog, mobile menu, FAQs and reduced motion.

Every account, activity metric, price and routine is a product preview: no backend, authentication, payment or subscription. State is memory-only and resets on refresh. No storage, cookies, telemetry, external runtime resources, environment variables or identity fields.

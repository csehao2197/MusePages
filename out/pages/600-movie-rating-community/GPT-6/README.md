## Features

Discover six illustrated fictional films; navigate film details, a mixed review desk, the 100-film canon, personal shelves, and a taste dashboard. All 100 canonical titles and deterministic rating distributions come from one catalog. Ratings update aggregates reversibly, mark films watched, and reconcile charts and library counts. Watched and queued lists are mutually exclusive. Search, combined filters, progressive rows, helpful votes, essay expansion, short-take/essay editing, previews, drafts, and diary reset work locally. The initial diary contains 47 watched films, 18 queued films, and 12 authored reviews.

The six declared generated illustrations and seven Latin font files are self-hosted. Other posters are original deterministic genre-specific SVGs. No runtime external requests, accounts, real users, authentication, publishing service, or backend exists. Storage failures fall back to memory. Every film, reviewer, director, and aggregate is fictional.

## Scope and adaptations

This authorized collection entry uses browser-native HTML, CSS, ES modules, and native dialogs instead of the requested Vite/React/TypeScript build. No build was authorized or run, and there is no `dist` build or framework source tree. Public resources are copied independently into `out`; private metadata, documentation, tests, and screenshots stay outside that export. Content data lives in `content.js`; UI templates and their English labels live in `app.js`, rather than the requested all-copy TypeScript module.

The collection scope is an interactive static homepage and companion hash views, not a production community. The fictional community totals are fixed seeds, with only this browser's actions added. Local moderation gives feedback only; it does not file an online report. Browser datalist supplies the searchable film picker. System-level dialog focus management is supplemented by a keyboard focus trap. No network activity is simulated. Desktop and mobile screenshot inspection, static validation, preview generation, and disabled registration must all succeed before completion is recorded.

Registration is disabled and undeployed; no collection assembly, publication, upload, commit, or shared workflow changes are included. `task\TASK.md` was absent at preflight; this explicitly scoped coordinator job supplies the authorized task.

CLEAR ABOUT THE BOUNDARIES

A pod concept.
Not a live PSA connection.

This standalone page is a gateway to an explicitly fictional demo. A real TicketWise pod would require a verified ConnectWise Hosted API session in the ticket iframe. This preview does not accept a session or exchange postMessage credentials.

What really works here
Two sample ticket contexts, nine commands, source-linked responses, bounded keyword matching, rich/plain-text clipboard attempts, and separate in-memory conversations. The local 30-reply guard is per tab, not an authenticated-member security control.
What stays fictional
Companies, devices, notes, addresses, past tickets, and responses. History uses a fixed sample clock of 12 Nov 2026, with 90-day company and 14-day global windows.
What is not connected
Next.js server actions, ConnectWise APIs and verified sessions, cookies, OpenRouter/Kimi, live permissions, persistent storage, customer messaging, and ticket modification. Clipboard support depends on browser permission.

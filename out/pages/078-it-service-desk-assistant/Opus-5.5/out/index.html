How it works

From ticket open to answer in one round trip

  1. 1Open a ticket

    The TicketWise tab loads as an iframe inside the ticket view.

  2. 2Handshake

    The host posts the member's session to the pod. The pod accepts messages only from allowed host origins.

  3. 3Fetch context

    Ticket, notes and configurations load in parallel as the signed-in member.

  4. 4Ask

    Slash command or free text. Similar-ticket search covers your company's last 90 days, then everyone's last 14.

  5. 5Answer

    Markdown answers with one-click rich-text copy for email and chat.

Security & permissions

It sees exactly what you see. Nothing more.

Runs as the signed-in technician

Every API call uses your own verified Hosted API session, so your security role applies. If you can't open a ticket in the PSA, TicketWise can't either.

Origin-checked handshake

postMessage events from anything but the allowed host domains are ignored. Session cookies are HTTP-only, Secure and SameSite=None for the cross-site iframe.

Pod Mode Only

Opened directly in a browser, the app shows a locked screen. Try the switch in the demo bar above.

30 requests per minute

Per-member rate limiting keeps model spend predictable. The demo counts down live.

Read-only by design

No ticket updates, no time entries, no status changes. Drafts are yours to paste.

Session-only history

Chat lives in the browser tab and clears with /refresh or when you close it.

Setup

Add the pod in a few minutes

  1. Deploy the app to your own host and set the environment variables.
  2. Create a Hosted Tab pod on the Service Ticket screen and point it at your deployment URL.
  3. Grant API access to the members who should see the tab. Their security roles carry through.
  4. Open any ticket. The TicketWise tab handshakes and is ready.
.env
OPENROUTER_API_KEY=sk-or-…
OPENROUTER_MODEL=moonshotai/kimi-k2.5:nitro
CW_SITE=na.myconnectwise.net
CW_ALLOWED_ORIGINS=https://na.myconnectwise.net
CW_CLIENT_ID=…
RATE_LIMIT_PER_MINUTE=30
MAX_COMPLETION_TOKENS=4096
SIMILAR_COMPANY_DAYS=90
SIMILAR_GLOBAL_DAYS=14

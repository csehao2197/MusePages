# Dusk Track Racing Game

Generated by **gpt-6.1-sol**, public model **GPT-6**. Original input:
`data\prompts\610-dusk-track-racing-game\610-dusk-track-racing-game.md`.
Design: `src\workflows\AI Agent\DESIGN.md`.

## Play

Serve `out\` with the repository's `startPreviewServer` from
`src\workflows\script\generate-preview.mjs`. The final public mount is
`/pages/dusk-track-racing-game/GPT-6/index.html`. No build or backend is needed.
Source browser modules live beside this README; `out\` contains only public files.

Three laps, three rail-driven rivals, ordered checkpoints, banked track, obstacle
collisions, off-track recovery, reverse, drift/boost, synthesized optional sound,
minimap, pause/countdown/podium, touch steering/pedals, and local best-lap ghost.
Use Controls in the game for keys. Race progress and times come from simulation.
Unfinished podium rows say Racing rather than inventing a finish time.

## Adaptation and limits

This authorized no-build adaptation uses native JavaScript modules and local
Three.js instead of the requested Vite/TypeScript compilation pipeline.
Dependencies are scoped to this model's package. No backend, network API,
multiplayer, analytics, credentials, or environment variables. Rivals are local
simulation, not online players. Best laps are saved only in this browser; denied
or corrupt storage does not prevent driving. Geometry is original code based on
the supplied specification, not downloaded art. UI and scene are English.

## Validation

Run `node out\pages\610-dusk-track-racing-game\GPT-6\.checks\qa.mjs` from the
repository root. Private evidence is in `.checks\qa.json`, desktop/mobile PNGs,
and the core-race test details. It checks final-subpath HTTP/resources, real
keyboard/touch input, pause/reset, race physics and completion, ghost persistence,
reduced motion, WebGL fallback, and overflow. Visual review is recorded only
after opening both actual images. `out\preview.png` is captured separately by
`StaticHomepage.ensurePreview`; both static and image digests are retained.
Registration is disabled and undeployed. No production build or publication.

Verified results: 20 QA assertion groups passed at 1200×900, 390×844, and
1440×900 (reduced motion). All ordinary browser resource/console/page error
collections were empty. Both homepage PNGs, both driving PNGs, the podium and
the fresh preview were opened for visual review. The mobile parked-car camera
was adjusted after the first image review so the entire car clears the sheet.

Run `.checks\full-heat.mjs` using Node from the repository root for the longer
real-browser test. Keyboard-event driving completed all three laps in **1:56.30**
simulation time (135.08 seconds wall time), with ordered gates, four actual
podium rows, a saved/reloaded best lap and Clear ghost verified. It writes
`.checks\full-heat.json` and `podium.png`. A separate fixed-step physics run
demonstrated an attainable first place at **1:40.30**. Those are test results,
not hard-coded game times.

## Scope and limits

This is a static homepage adaptation, not the requested production WordPress/Elementor/Bootstrap service. Six original introductory learning notes link to established sources; they are not expert-authored or exhaustive scientific reviews. All illustrations are original conceptual artwork. All map pins are fictional and explicitly labeled. The calendar downloads tomorrow’s personal observation reminder, not a real community event.

The commute calculator uses explicitly stated fixed teaching factors (solo car 0.20, bus 0.08, rail 0.04, walking/cycling 0 kg CO₂e per passenger-km). These are not live regional statistics or a measured personal footprint; lifecycle effects are excluded. There are no fabricated community totals.

Saved resources and completed knowledge checks persist only in this browser when storage is available. There is no account, authorization, CMS, forum, contribution upload, backend API, partnership, behavior analytics, push notification, or cross-device profile. No real location is requested. The English-only collection constraint supersedes the original multilingual request. No builds, deployment, or publication are performed; registration is disabled by default.

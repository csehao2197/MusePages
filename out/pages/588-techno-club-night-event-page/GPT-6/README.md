## Features and limits

Phase Assembly takes place at the fictional Copper Vault in West Briar. The fictional lineup, address, ticket estimates, travel notes and zone descriptions are rewritten for this variant. Original chrome SVG artwork, four artist signal emblems, deterministic local audio synthesis, real analyzer waveform/spectrum, volume and independent visual pause, saved running order, accessible venue selector, validated local ticket-plan drawer, policy and native FAQs are implemented.

No backend, API, payment, real availability, ticket, admission reservation, calendar date, analytics or real venue-access assurance exists. Plans/bookmarks use this browser's localStorage; storage failure is disclosed. Audio only starts after a deliberate gesture; reduced motion freezes artwork and samples textual level at 2 Hz. Device speakers and browser audio permission affect audibility.

**Authorized adaptation:** standalone HTML/CSS/browser ES modules replace the requested Vite/React/TypeScript build. No build was authorized or run. `content.js` replaces `src/content.ts`; no server or transpilation is necessary. Original WAV synthesis is run directly with Node, not as a build hook. Anton's actual Fontsource font has weight 400 only; its native condensed display face is used rather than claiming a nonexistent 700 face. Plex is bundled at 400/700. No exact external image is specified or needed.

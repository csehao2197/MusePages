BEFORE YOU START

Good questions.
Straight answers.

Is this connected to Stellar Testnet?

No. There is no RPC, wallet, issuer verification, contract, signature or transaction. All rewards are fictional labels.

Can I earn or deposit funds here?

No. Claiming, approving, completing and refunding change in-memory sample records only. Refreshing resets them.

Are pull requests actually verified?

Only HTTPS GitHub URL shape and the expected owner/repository are checked locally. Existence, PR author, commits and merge status remain unverified.

Where is my draft saved?

In this browser tab's memory, up to 12 total samples. Nothing is uploaded or persisted. Reloading clears all changes.

HONEST BY DESIGN

A blueprint, not a bank.

This independent Stellar Forge concept adapts a full-stack marketplace specification into a static homepage and local lifecycle walkthrough. It is not affiliated with Stellar or any featured fictional project.

No wallet, RPC, Soroban contract, asset issuer verification, GitHub API, OAuth, database, AI provider, signature, funds or chain transactions are connected. “Approved”, “completed” and “refunded” are local sample states, not financial facts. Demo identities are not authentication or a security boundary.

Claim → submit → owner approval → completion, draft opening and pre-claim cancellation/refund are simulated. PR validation checks URL shape and repository only. Disputes, real expiry processing, accounts, reputation and deployment are outside this prototype. No platform fees are collected.

All changes live only in memory and reset on refresh. The illustration is original SVG; Inter and Lucide licenses are included with the static assets.

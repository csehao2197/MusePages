OPERATIONAL BOUNDARIES

Expose deliberately. Observe carefully.

01 / DOCUMENTATION

Dev & stage only.

Generated springdoc OpenAPI at /api/docs/openapi.json and Swagger UI at /api/docs are readable without login only when enabled in those profiles. Production serves neither. Actual operations still require a session; changing requests require CSRF proof.

02 / MANAGEMENT

A separate port.

Actuator defaults to 9091 on the metrics network. Application-port /actuator returns 404. Health/readiness and Prometheus are default; dev/stage expose all management endpoints. Ingress routes management only in dev/stage per this backend source.

03 / TELEMETRY

IDs, not content.

Structured JSON lines carry request IDs and opaque Keycloak subjects. Micrometer reports route/status, connection-pool and JVM metrics. Audit records location/tag changes with action, entity type and ID — no content.

Build, formatting & dependency policy

Maven builds the Java service. Open Java Format uses a single 120-character style, rewrites in normal process-sources and checks with CI or -Pformat-check. Formatter/POM versions are managed explicitly. Patched Boot-managed libraries may use BOM property overrides until Boot catches up. This frontend neither runs these tools nor claims their checks passed.

Future consumers, same API.

Bearer-token resource-server support and an MCP adapter belong to later client work. They are not represented as working integrations here.

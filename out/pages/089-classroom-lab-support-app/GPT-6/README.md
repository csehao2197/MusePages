# LabRescue 课堂支持概念

- 输入：`data\prompts\089-classroom-lab-support-app\089-classroom-lab-support-app.md` 与 `src\workflows\AI Agent\DESIGN.md`；真实模型 `gpt-6.1-sol`，目录 `GPT-6`。纯 HTML／CSS／JavaScript；原创教室 SVG、许可齐全的本地 Inter 和 Lucide。
- 源码位于本目录，独立静态版本为 `out\`；通过现有静态 HTTP 服务访问 `out\index.html`。预计公开路径 `pages/classroom-lab-support-app/GPT-6/index.html`，发布登记默认关闭。
- 支持三类报告、独立案例、固定非侵入式观察记录／停止升级、撤销最近结果、确认维修后归档、搜索、15 分钟确定性备用活动及两种浏览器打印。检查为演示文本，以学校政策及合格人员判断为准。
- 使用版本化、校验后的 `localStorage`，上限 30 个案例；本地明文、同浏览器设备独享，清除浏览器数据可能丢失。读取损坏数据时保留原值并阻止写入；写入失败／其他标签修改时拒绝应用变更，可重试或主动进入刷新即失的临时内存模式。
- 静态适配采用手工数据校验与原生 dialog。原输入提及的 PRD 未提供；Next.js、Zod、Gemini、服务端密钥、账号、技术员通信、远程修复、仓库发布及演示视频均属原系统范围，当前仅交付可独立静态部署的首页流程。环境变量和外部网络服务均不需要；备用活动固定模板，材料备注不是设备依赖。
- 已通过语法检查、5 项逻辑测试与 130 项静态／浏览器检查；实际覆盖三种案例路径、独立历史、刷新恢复、停止升级、撤销、维修确认、模板活动、草稿保护、写入失败／跨标签冲突回滚、损坏数据保留、临时模式、文本转义及 320–1440 响应式。打印按钮调用与 Chromium 实际 PDF 渲染均已验证，并查看桌面／手机、案例、活动编辑、停止、恢复、打印和真实预览。入口 `engine.test.mjs`、`verify.mjs`，记录位于 `.checks\`。

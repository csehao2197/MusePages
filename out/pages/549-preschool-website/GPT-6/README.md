## Experience

Three age programs with ratios and schedules; seven daily timeline stops; three explicitly fictional teacher portraits; five monthly tuition rows; five keyboard-accessible FAQs; weekday/time radio chips; age selection; kindly validated first-name and phone inputs; browser-only confirmation; saved drafts and prefilled editing. All school, address, tuition, licensing and staff facts are invented. No children are pictured.

All six exact template photos are self-hosted. Baloo 2 and Nunito Sans are self-hosted Fontsource fonts. Icons are inline output of the installed Lucide package. Content, rates, hours, links and image paths live in `content.js`; styles use the specified palette, rounded typography, warm-paper sections and reduced-motion support.

## Authorized static adaptation

The original asks for Vite 5, React 18, TypeScript, Tailwind 3.4, Motion and a production `dist` build. This delivery uses native HTML/CSS/JavaScript and the authorized `out` static export instead: no framework runtime, bundling, hashed assets, TypeScript component tree, React external store or production build. IntersectionObserver/CSS replace Motion; CSS tokens replace Tailwind; guarded localStorage replaces the React store. This is a homepage adaptation, not exact stack compliance. No dependencies were installed.

No backend, external API, analytics, environmental secrets or form transmission exists. The booking is a local plan, not a real reservation; blocked storage displays a warning. Use example personal details. The footer phone and email are fictional examples, not active school contacts.

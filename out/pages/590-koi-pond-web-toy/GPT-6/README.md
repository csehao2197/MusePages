## Implementation

Source is this model directory. Static delivery is `out\`, containing only HTML, CSS, browser JavaScript, three local Latin fonts, favicon, licenses and the actual generated preview.

The viewport is the whole site. Nine seeded, independent koi use a following spine, travelling body waves, fins, bounded steering, separation, kick/glide motion, tap response, food pursuit and actual pellet consumption. Tap for concentric ripples; hold for food; drag for a current that influences fish and floating particles. Four seasons include petals, lotus, ginkgo and cracked ice. Day/night and rain/snow blend continuously. All drawing is original Canvas/WebGL/SVG code; there are no image textures, sampled audio or external runtime requests.

The dock supports seasons, night, rain/snow, synthesized sound and a wall-clock 25-minute focus timer with pause, resume, completion chime and another round. Ambient audio is off until explicitly enabled. Keyboard: 1–4 seasons, N night, R rain, M sound, F focus, Space pause/resume during focus, Escape exit. With the pond focused: Enter ripples, hold Space to feed, arrows draw a current. Reduced motion is supported live. Phone quality reduces fish and particle counts. `window.__pond` is frozen and exposes first-frame timing, tier and rolling fps.

## Static adaptation and limits

This authorized, build-free adaptation uses native JavaScript modules rather than the requested Vite 5/TypeScript source/build layout. The conceptual scene modules are retained; there is no production build and no backend or mocked server. Only the declared font/icon asset dependencies were installed locally. Fonts are copied unchanged from Fontsource; Lucide SVG contents are inlined in a local module.

Physics and watercolor effects are lightweight procedural approximations, not fluid dynamics. The low tier uses nine-point spines; surplus fish leave the edge on quality reduction. The 2D water fallback uses generated, drifting caustic tiles without WebGL ripple refraction; it is also selected for software WebGL renderers to avoid expensive GPU readback. Pad and lighting transitions use continuous exponential easing rather than exact-duration authored spring curves. Snow, dragonfly and leaf paths are simplified. Wake lock depends on browser permission/support. Performance measured in automated headless Chromium is machine-specific, not a universal 60fps guarantee. No full 25-minute real-time endurance or physical-device/audio listening test is claimed.

## Running and validation

Serve **only `out\`** with a static HTTP server. The repository's `startPreviewServer` from `src\workflows\script\generate-preview.mjs` serves it at `/pages/koi-pond-web-toy/GPT-6/index.html`; no Vite or Next server is needed. Optional `season=spring|summer|autumn|winter`, `night=0|1`, `rain=0|1` query values restore a scene.

Private checks and actual screenshots are in `.checks\`; run from the repository root:

```powershell
node out\pages\590-koi-pond-web-toy\GPT-6\.checks\qa.mjs
```

Final measured results, viewports, assertions, browser errors and visual-review evidence are recorded in `.checks\qa.json`. The source and static output are independently checked with `StaticHomepage`; the workflow creates the real 1200×900 preview and digest. Source/input fingerprints and `metadata.json` remain private. Registration is disabled and undeployed; no build, gallery assembly, publish or upload was performed. No environment variables, credentials, analytics, cookies or persistence are required.

Verified on 2026-11-16: all 12 check groups passed in installed Chromium, with no console output, HTTP failures, failed requests, page errors or external requests. First fully drawn frames were under two seconds at 1200×900 and 390×844; initial fish counts were nine and five. Actual feeding consumed pellets, current forces were checked, and keyboard, single/multi-touch, all seasons, ice cracks, sound state, focus pause/completion/restart, query overrides, reduced-motion changes, rotation and forced 2D fallback were exercised. Timer completion used a controlled wall-clock advance, not a 25-minute wait. The software renderer successfully compiled the shader and selected the Canvas fallback; hardware GPU visual performance is not certified. Exact frame timings, fps and resource sizes are in `.checks\qa.json`; browser modules are about 24.5KB gzipped and public resources including preview are under 1MB.

The actual `.checks\desktop.png` and `.checks\mobile.png` were opened and visually reviewed after the final code changes: title/pond hierarchy, cream-on-teal contrast, fish/tail continuity, plant spacing, legible hints and an unclipped eight-cell mobile dock. The winter/night screenshot was also inspected. The final workflow preview is reviewed separately and its fingerprint verified before completion.

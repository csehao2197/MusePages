## Features and boundaries

An invented Port Meridian aquarium: five linked floor-map zones, four animal portraits, a seven-day feeding schedule, bounded guest steppers, four sample entry slots, locally saved and restored visit choices, informational memberships, sample hours, mobile navigation, keyboard controls, and reduced-motion support. The sold-out slot cannot be selected. A local save is not a reservation or payment. Schedule days use a fixed sample pattern, never the real clock. Displayed hours do not determine sample picker availability.

This is the authorized build-free HTML/CSS/ES-module adaptation, not the requested Vite 5 / React 18 / TypeScript / Tailwind 3.4 application. `content.js` centralizes content, images, links and data in plain JavaScript instead of typed `src/content.ts`. CSS replaces Motion with slow caustics, portrait float, entry reveals and click transitions. Lucide SVGs are statically rendered from the existing package into `icons.js`; six specified photographs and all six font weights are self-hosted. No backend, network API, checkout, authentication, environment variables, analytics or CDN runtime is needed.

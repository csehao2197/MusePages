## Features and boundaries

Six supplied, locally downloaded illustrations; an original SVG orbital card back; tactile shuffle/flip state machine; date-seeded, versioned and validated local-day reading; distinct Fisher–Yates three-card spreads with independent reversed orientations; keyboard-accessible native card dialogs; browser-only private journal; locally rendered 1080 × 1350 Canvas PNG download; responsive gallery, guide, and FAQ.

All readings are fictional symbolic prompts for entertainment and reflection, not predictions or medical, mental-health, legal, financial, relationship, or safety advice. No account, external AI, backend, network submission, analytics, or remote randomness. Nothing is uploaded. Journal and daily-card persistence depend on browser storage; a deterministic daily draw still works when storage is blocked. Clearing browser data removes saved notes.

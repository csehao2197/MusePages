## Implementation

Source: `out\pages\546-surf-school-website\GPT-6\`. Static export: its `out\` folder; intended public address `/pages/surf-school-website/GPT-6/index.html`.

The authorized **no-build HTML/CSS/browser-JavaScript adaptation** replaces the requested Vite 5, React 18, TypeScript compilation, Tailwind 3.4 and Motion runtime. `src\content.ts` is plain, TypeScript-compatible content data copied unchanged to public `content.js`. CSS tokens, native SVG, IntersectionObserver and CSS/Web Animations implement the visuals and motion. Lucide icon geometry is extracted from the existing ISC-licensed package. Eight local Fontsource WOFF2 files cover all requested families and weights.

All nine sections are present: fixed navigation, full-bleed wave, five SVG sample forecast days, three lesson levels, editorial packages, coach photos, booking, coastline map and footer. Lesson links preselect their level; package links preserve the package in the request. Native radio chips support keyboard navigation. The surfers stepper is bounded to 1–6. Name/email validation, local saving/restoration and graceful storage-failure handling are included. Mobile navigation closes on link, Escape, outside click or desktop resize. Reduced-motion mode removes zoom, loops, parallax and transform reveals.

The map is illustrative, the forecast is static sample data, and the booking is only a `localStorage.bookingRequest` mock: **no request, email, payment, reservation or network submission**. Contact details are fictional. No APIs, analytics, environment variables or credentials are needed. The original head-coach image is preserved; its displayed upper crop excludes dark board markings.

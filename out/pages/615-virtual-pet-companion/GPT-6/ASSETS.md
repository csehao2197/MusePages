# Assets and attribution

All pet poses, habitat, sprout/favicon, six aligned accessory layers, thumbnails, snacks, bubbles and particles are project-original code-drawn SVG/CSS/Canvas assets. No external image files, raster textures, live-demo code, existing characters or downloaded artwork are used.

## Icons

Selected `lucide-react` modules: Coins, House, Gamepad2, Shirt, Utensils, ShowerHead, Moon, Heart, Droplets, Zap, Play, Pause, RotateCcw, Trophy, ArrowLeft, ArrowRight, Lock, Check, X, Sparkles, ChevronRight.

Source: https://www.npmjs.com/package/lucide-react. Authors: Lucide contributors. License: ISC (including retained upstream notices), copied verbatim from the installed package into `Lucide-LICENSE.txt`. Only the selected SVG geometry is emitted to `icons.svg`; no CDN or browser React runtime is required.

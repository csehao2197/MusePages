Margin

A quieter way to understand a monthly plan.

Role: independent design studyDuration: not trackedClient: self-initiated fictional brief

Challenge

Financial interfaces can overload a first-time reader with choices.

Solution

One clear overview, a calm hierarchy and a single next action. All values are illustrative UI content, not financial advice or a real service.

Result

A focused original interface study. No usability study, launch or conversion result is claimed.

A closer look

Select an image to open the lightbox. Arrow keys move between images; Escape closes it.

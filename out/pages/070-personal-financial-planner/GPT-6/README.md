- 输入：`data\prompts\070-personal-financial-planner\070-personal-financial-planner.md` 与通用 `DESIGN.md`；真实模型 `gpt-6.1-sol`，目录 `GPT-6`。
- 原创暖白/森林绿财务仪表盘，Inter 与系统 Georgia、Lucide（许可随资源保留）；采用 HTML/CSS/ES Modules 静态首页，未声称使用 Next.js/React/TypeScript/Tailwind。源码在本目录，独立版本 `out\`，真实预览 `out\preview.png`。
- 收入、月度/一次性支出、储蓄目标可增改删；可设置预测起始月与期初可用现金、选择十二个月图表、查看精确数据表、规则式建议、导出真实计划 JSON/预测 CSV，并在校验与明确确认后恢复本地文件。
- 金额以整数美分计算；每月付款按首次日期日号重复并截断至月末，双周收入按实际十四天日期计数。目标剩余金额按含截止月的月份均分、向上取整美分，末笔封顶；逾期目标首月分配剩余金额。新增目标分配从可用现金扣除，已有储蓄独立计入，避免重复计数。
- 完整日历月估算，非银行余额或月内现金时序；负值保留并标注资金缺口。图柱高度为有符号余额的绝对幅度，负值使用赤陶色，精确表格和按钮保留符号。目标月度分配不是实际转账，也不是截止日期达成保证。
- 所有默认数据明确为样例；无银行、账户、后端、投资收益、税务优化或支付服务，无环境变量。规则建议仅基于已输入金额，非财务/投资/税务建议；未输入的税费、通胀和利息不作估算。
- 数据只在标签页内存，刷新清空；无 Cookie、localStorage 或自动保存。JSON 文件包含用户自行输入的财务信息，仅本地读写；应自行妥善保管。导入 ≤1MB，严格版本/字段/日期/金额/唯一 ID 校验后原子替换；每列表 ≤200 项，每金额 ≤$10,000,000，输入日期 2020–2100。

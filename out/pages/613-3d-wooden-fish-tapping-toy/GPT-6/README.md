## Play

Tap the raycastable carved 3D instrument, press Space outside controls, or activate **Strike the wood** with mouse, touch, Space or Enter. A separate padded mallet, sprung body, bounded particles, ground ripple and calm message respond. Today is saved by local day; Session lasts for the page visit. Rhythm chains taps less than 1.6 seconds apart. Sound and synthesized ambience are independent. Auto taps every 1.2 seconds. Hidden tabs stop automatic play and suspend audio; deliberate controls resume it.

## Static adaptation

No build is run or required. Native JavaScript modules replace the requested Vite/TypeScript application framework under the authorized static adaptation. `src\content.ts` uses JavaScript-compatible TypeScript; all visible copy is centralized there. Browser modules are syntax-minified into `out\` without bundling or a production build. Three.js and the specified local Latin Fontsource files are reused from existing licensed packages/assets in the workspace; no dependencies were installed and no runtime network services are used.

Geometry, wood grain and all sound are procedural and original, not imported models, illustrations or recorded audio. The public scene uses actual Three.js WebGLRenderer; an explicitly labeled Canvas 2D instrument is used only when WebGL initialization fails. There is no backend, mock sound, account, medical claim or spiritual reward. The room name is an abstract architectural setting. No Chinese glyphs, calligraphy or merit labels are used; the English adaptation uses “Today,” “Rhythm” and “+1 calm.”

Daily saving has an in-memory fallback when storage is denied. Saved ambience is intentionally not auto-started on reload, so audio always needs a deliberate gesture. Sound synthesis availability depends on the browser. Actual human listening is not claimed by automated audio checks.

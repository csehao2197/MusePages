- 原始输入：`data/prompts/095-knowledge-capture-dashboard/095-knowledge-capture-dashboard.md`；设计指引：`src/workflows/AI Agent/DESIGN.md`；真实模型：`gpt-6.1-sol`，目录 `GPT-6`。
- HTML/CSS/ES modules 静态首页；双栏捕获列表/原创 SVG 图、真实缩放/平移/节点详情、标题/摘要/标签搜索、最多 12 个双跳节点、6 条分页、100 条捕获上限；新建集合、单项/批量分组与级联删除。
- 捕获仅处理用户粘贴的正文或视频字幕；摘要为前两句（最多 420 字符），标签来自固定关键词或手工输入，图边表示共享标签。没有抓取、语义向量或 AI；视频缺字幕显示明确错误。

- 所有变更仅在当前标签页 RAM，刷新重置；导出实际 JSON。删除同步清除复习、集合关联及受影响摘要组。设置控制关键词标签与图中标签节点；重置需确认。
- 本版不提供 Next.js、Plasmo 扩展、Supabase、认证、BYOK/密钥输入存储、真实 LLM、自动 Agent、同步、付费或后台；不是已部署的完整 PRD 产品。无环境变量；仅使用公开/样例文本。
- 目录内 `index.html` 可由静态 HTTP 服务访问；独立版本 `out/`，候选公开路径 `pages/knowledge-capture-dashboard/GPT-6/`；候选集合位置 `deploy/dist/MusePages/`。登记默认关闭，本轮不构建或发布。

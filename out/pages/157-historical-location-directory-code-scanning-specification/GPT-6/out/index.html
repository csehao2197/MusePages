BEYOND CODEQL

One job.
One clear responsibility.

Security analysis, shell checks, workflow validation and Java formatting are distinct checks.

CodeQL / supported source

Java/Kotlin uses build mode none. JavaScript/TypeScript includes source variants. Python matches tracked *.py. Actions analysis covers workflows and local actions. A first job inventories tracked and changed files; languages without code are omitted. Shell is not supported.

ShellCheck / shell warnings and errors

tools/shellcheck.sh selects tracked files with a shell shebang, excluding third-party mvnw. Notes are excluded. Its workflow reacts to shell, hook or workflow changes on pushes to main and pull requests.

actionlint / syntax and wiring

tools/actionlint.sh uses the installed tool or a pinned container. It checks action inputs, needs references, reusable workflow inputs and expressions. Workflow or script changes trigger it; any finding fails the check.

Java format / source consistency

tools/java-format.sh check checks without editing. Java, POM or workflow changes trigger the dedicated check. It also participates in CI and the staged-Java pre-commit hook. Failure is a check, not a security alert.

Trigger boundaries / allow-list main

Pushes name only main. Historical development and dependency-update branches receive no push analysis. Pull requests into main remain eligible, including dependabot and renovate heads. Markdown-only pushes and PRs are ignored; weekly schedules still run.

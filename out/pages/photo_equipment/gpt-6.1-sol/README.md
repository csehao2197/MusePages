# LUMEN photography equipment

Responsive static brand storefront generated by **GPT-6.1 Sol (`gpt-6.1-sol`)** from `src\prompt_test\photo_equipment.md`. The user authorized this local Markdown as the authoritative input because there is no matching `data\prompts\` entry or `task\TASK.md`.

## Implementation

Source: `index.html`, `styles.css`, `app.js` in this directory. Standalone static output: `out\index.html` with local assets. Plain HTML, modern CSS, and browser JavaScript keep the page independently deployable without a framework runtime, build, environment variables, or external requests.

Features include Acrylic navigation, a cinematic camera hero, six feature panels, Mica-inspired storytelling, three interactive component hotspots, magnified product views, three lenses, six gallery filters and lightboxes, configurable camera purchasing, and a local-storage shopping bag with quantity controls and demo order review. Native dialogs support keyboard dismissal and focus restoration; reduced motion and blocked browser storage are supported.

## Run and validate

Serve `out\` with any static HTTP server, or open `out\index.html` directly. HTTP serving is recommended for consistent SVG sprite and download behavior.

From the repository root:

```powershell
node src\prompt_test\prepare-lumen.mjs
node src\prompt_test\verify-lumen.mjs
```

Preparation copies source and generates local Lucide assets; it does not build. Verification uses existing Playwright Chromium and the repository loopback preview server, then closes both. It checks resource loading, camera exploration, filters, dialogs, downloads, cart arithmetic and persistence, malformed/blocked storage, reduced motion, and overflow at 320/390/768/1200/1440px. Evidence is saved in `src\prompt_test\lumen-checks\`; the real 1200 × 900 homepage preview is `out\preview.png`.

## Scope and limitations

LUMEN hardware, specifications, pricing, financing, shipping, and warranty are fictional. Checkout reviews an order but never processes payment or personal information. Product photographs illustrate real third-party cameras and lenses, not manufactured LUMEN hardware; the gallery is not an X1 performance sample. Product view controls magnify regions of a photograph rather than providing a 3D model. “Watch the Film” plays a silent photographic montage, not a recorded commercial. Companion apps, firmware, support, and social accounts are explicitly conceptual.

Images are sourced from Unsplash; exact original image links and the license link are in `out\assets\image-credits.txt`. Lucide icons retain their bundled ISC license.

No build, shared deployment configuration change, local collection assembly, or online publication is performed. `config_added` remains false. Future collection registration should use the existing repository workflow and preserve other works.

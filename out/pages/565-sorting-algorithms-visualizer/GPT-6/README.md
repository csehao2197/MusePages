## Implementation

HTML/CSS/native browser ES modules, with source in this directory and an explicit allowlisted static copy in `out\`. No backend, mocks, APIs, persistence, analytics, environment variables, or third-party requests. All operations and metrics are computed locally.

Five pure sorting algorithms emit full operation traces without mutating input. Seeded mulberry32 arrays, prefix metrics, snapshots every 256 operations, reversible scrubbing, keyboard transport, hover values, canvas markers, measured complexity cards, four-pattern heat table, and a shared-tick two-lane race are implemented. The race uses identical array copies, disables duplicate lane choices and freezes finished lanes. Reduced motion starts paused and suppresses slides/sweeps. Slow swaps slide; normal playback cuts; completion sweeps are canvas-drawn.

The authorized static adaptation replaces the requested Vite 5 / React 18 / TypeScript UI / Tailwind 3.4 pipeline with native ES modules and CSS tokens. Engine files are JavaScript with a TypeScript step contract, rather than a compiled TypeScript/React component tree. Copy is centralized in `content.js`; Lucide geometry is extracted from the installed package without bundling React. The exact requested font families are self-hosted. No build was run. Export is `out\`, not the original prompt's `dist\`.

## Scope and limits

This is the complete standalone homepage/tool, not a production learning platform or a benchmark of CPU execution time. Each compare, swap, write or final-mark event counts equally. Merge buffer copying and snapshot overhead do not count as operations; worst-case quicksort auxiliary space can be linear despite the displayed average-space summary. Browser scheduling can throttle playback in background tabs. Race results are deterministic step counts, not time rankings.

Registration is opt-in and disabled; no collection build, dist, publish, upload or deployment is part of this delivery. Final publication, if later authorized, is handled by the existing MusePages workflows.

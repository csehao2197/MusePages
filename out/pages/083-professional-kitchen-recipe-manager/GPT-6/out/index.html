AN HONEST LITTLE DEMO

A recipe book, not a backend.

Search, favorites, a four-step wizard, editing, confirmed deletion and a touch-friendly focus view work locally. Original sample recipes and edits live only in browser memory; reload restores the samples.

Workspace switching illustrates scoped reads and writes. This is not secure multi-tenancy: all fictional data is in the source. There are no accounts, server, database, hardware connection, inventory, costing or scaling services.

The route examples use hash navigation for independent static hosting. Local operation feedback and a 650 ms failure simulation illustrate rollback, not a real API response.

SPECIMEN / NOT COLLECTED TELEMETRY

KEEP THE WRITE PATH SMALL
Collect. Don't intercept.
Services write stdout; Docker rotates json-file logs. Alloy mounts log files read-only, not the root-equivalent Docker socket. No Loki logging driver. If Loki is down, Alloy retries then drops lines; application writes and docker logs remain unaffected.
PRIVATE BY DESIGN
Pull, don't publish.
Prometheus joins the metrics-only network. No monitoring port is public. Backend and Keycloak use management ports; nginx and database have exporters. Only dev/stage expose backend /actuator/ through ingress. Production does not.
KNOW WHAT'S NOT HERE
Later is a real boundary.
Distributed traces, browser telemetry and alert routing are future work. Identity events stay in Keycloak's event store and metrics, not logs. Audit lines carry audit=true for separate retention. Retention periods, volume sizing and stack deploy tooling remain open.
Separate monitoring storage preserves history across application releases. Optional developer monitoring starts manually. This static page creates no containers, collectors, dashboards, traces or network connections.

## Implementation

Source is this model folder; independently served static resources are in `out\`. No backend, remote assets, analytics, credentials, or mocked gameplay. Only the mute preference uses localStorage.

The actual game has a primitive-built fighter and drones, seeded faceted asteroid scenery, chase camera, bounded flight volume with automatic return, keyboard/pointer/touch steering, pooled player/enemy projectiles, collision-based shields, regeneration, boost cooldown, protective roll, hold-to-lock homing missile, enemy pursuit/fire/separation, escalating endless waves, circular local-frame radar, wave-clear success, shield-loss/retry/title states, and synthesized tones. Asteroids are not colliders.

This is an authorized no-build adaptation: native browser JavaScript modules, CSS and locally installed three.js 0.170.0 replace Vite/TypeScript/Tailwind compilation. Fontsource fonts are self-hosted. No build was run. Score and wave-clear feedback are added for this task; there is no final campaign win, consistent with the original endless patrol. Named variables live in content.js, gameplay constants in tuning.js.

Limits versus the detailed target: particles use a bounded pool of meshes rather than one InstancedMesh; synthesized cues are simplified, missile trails and emissive hull flash are omitted; copied modules are not minified. The title composition uses a 40px desktop inset and an offset chase framing; mobile framing aims lower to keep the fighter above the sheet, whose primary action stays visible while instructions scroll. Text labels are also in HTML/main.js rather than entirely centralized. Gameplay remains fully local and replayable.

## Run and verify

Serve only `out\` at `/pages/space-dogfight-arcade-game/GPT-6/index.html`, using `startPreviewServer` from `src\workflows\script\generate-preview.mjs`; no development/build server is needed. The installed Chromium and `@playwright/test` support private QA.

Private evidence: `.checks\qa.json`, `.checks\desktop.png`, `.checks\mobile.png` and gameplay screenshots. Public `out\preview.png` is generated with `StaticHomepage.ensurePreview`; static/input/image fingerprints are private model-root files. Verification outcomes and actual visual review are recorded in `.checks\qa.json`. Registration is disabled and undeployed; no dist, publish, or upload is performed.

The actual Chromium checks cover both title and active gameplay at 1200×900 and 390×844, before/after-interaction overflow, keyboard/pointer/touch controls, player and enemy firing, lock/missile hits, two-bolt drone collision, six-hit player loss, score/wave-clear/breather/escalation, regeneration, roll protection, boundary return, mute preference, restart/title, and reduced motion. Deterministic collision fixtures place real projectiles and drones through the real collision code; independent live-input and pursuit tests run alongside them. Both actual title PNGs and gameplay/retry PNGs were opened for visual review. Review identified and corrected the mobile fighter/card overlap and disconnected asteroid faces before the final test pass.

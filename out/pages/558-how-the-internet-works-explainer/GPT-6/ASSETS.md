All diagrams and illustrations are original code-drawn SVG in this project. The abstract landmasses use deterministic ellipses and a sine-wobble boundary, not geographic data.

Font packages are installed locally under this model's source directory. Lucide 0.468.0 is copied from an existing installed repository dependency; unused icons, source maps and package sources are not exported. Used icons: CornerDownLeft, Timer, Search, Play, RotateCcw, ArrowUp. Font/icon license texts are included under `out\licenses`.

LeekShop is an original storefront concept about a very ordinary vegetable having an unusually good time. A desk companion. A slightly silly gift. A tiny reminder to make room for lightness.

Every product image here is an original illustration, not a photograph of available merchandise. The catalog, stock, prices and delivery estimates are fictional.

What really works

Search, categories, sorting, product details, bounded quantities, a browser-local cart, rule-based suggestions, validated demo checkout and a real JSON receipt download.

What this is not

No live inventory, real account, payment, order, tax calculation, fulfillment, Claude, LlamaIndex, MCP tools or backend. The source PRD’s completion claims describe its vision, not services connected to this page.

Cart data uses versioned localStorage. Corrupt or conflicting data is left untouched until you choose to reset or reload it. Temporary mode uses memory only. Cross-tab changes invalidate an open checkout; client-side checks are not a production security boundary.

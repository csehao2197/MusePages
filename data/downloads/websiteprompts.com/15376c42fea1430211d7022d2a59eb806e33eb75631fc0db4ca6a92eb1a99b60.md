Create a mobile app landing page:

1. HERO SECTION
- App name and tagline
- Compelling headline about app benefit
- Device mockup showing app (iPhone/Android)
- Download buttons:
  - App Store badge
  - Google Play badge
- Rating: "4.8★ on App Store"
- Download count: "1M+ downloads"

2. APP PREVIEW
- Phone mockup carousel
- Key screens showcased
- Animated transitions
- Or video demo

3. KEY FEATURES
4-6 app features:
- Feature icon
- Feature name
- Brief description
- Corresponding screenshot

Format:
- Feature + phone mockup pairs
- Alternating sides

4. HOW IT WORKS
Simple user flow:
1. Download the app
2. Create account
3. [Key action]
4. [Benefit achieved]

5. USE CASES
"Perfect for..."
- Different user types
- Different scenarios
- Benefits for each

6. TESTIMONIALS
App reviews:
- 5-star reviews from app stores
- User name and rating
- Review text
- "Verified user" badge

7. COMPARISON (optional)
"Why [App] vs Others"
- Feature comparison table
- Competitors (unnamed or named)
- Checkmarks for your advantages

8. SECURITY/PRIVACY
- Data protection
- Privacy commitment
- Certifications
- "We never sell your data"

9. DOWNLOAD CTA
- Repeat download buttons
- QR code for quick download
- SMS link to phone option

10. COMING SOON FEATURES
If applicable:
- Roadmap teaser
- "Coming in v2.0"
- Email signup for updates

11. FOOTER
- App links
- Company info
- Support/Help
- Social media

Design: App-focused, clean. Device mockups should look premium. Mobile version should make download super easy.

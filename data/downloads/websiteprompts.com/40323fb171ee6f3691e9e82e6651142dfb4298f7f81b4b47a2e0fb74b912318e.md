Create a product launch landing page:

1. HERO SECTION
- Compelling headline focusing on benefit
  - "The [Product] that [Solves Problem]"
  - "Finally, a [Product] that actually works"
- Subheadline expanding on the promise
- Product image/mockup (prominent)
- Primary CTA: "Get Early Access" or "Buy Now"
- Secondary CTA: "Watch Demo" or "Learn More"
- Trust badges or social proof

2. PROBLEM SECTION
"Sound familiar?"
- Paint the problem clearly
- 3-4 pain points users experience
- Use relatable language
- Build empathy

3. SOLUTION INTRODUCTION
"Introducing [Product Name]"
- Brief product description
- Hero product shot
- Key value proposition
- What makes it different

4. FEATURES/BENEFITS
3-6 key features:
- Icon or illustration
- Feature name
- Benefit-focused description
- Supporting image/screenshot

Layout:
- Alternating left-right
- Or feature grid
- Or tabbed interface

5. HOW IT WORKS
3-4 simple steps:
1. Sign up / Purchase
2. Setup (how easy)
3. Use (key action)
4. Results (what they get)

Visual step indicators

6. SOCIAL PROOF
- Customer testimonials
- Star ratings
- Review counts
- Media mentions
- "As seen in" logos
- User count: "Join 10,000+ users"

7. PRICING/OFFER
If selling:
- Price (with anchor price if discounted)
- What's included
- Guarantee/refund policy
- Limited time offer urgency

If free/freemium:
- Free tier benefits
- Premium upgrade tease

8. FAQ SECTION
5-7 common questions:
- What exactly do I get?
- How is this different from X?
- Is there a guarantee?
- How do I get started?
- Who is this for?

9. FINAL CTA
- Repeat the offer
- Urgency element
- Risk reversal (guarantee)
- Clear button

10. FOOTER
- Minimal - links only
- Privacy/Terms
- Contact

Design: Focus on conversion. Remove distractions. Strong visual hierarchy. Mobile-optimized.

Create a customer account dashboard:

1. LAYOUT
- Sidebar navigation (left)
- Main content area (right)
- Welcome message with customer name

2. SIDEBAR NAVIGATION
- Dashboard (overview)
- Orders
- Addresses
- Payment Methods
- Wishlist
- Reviews
- Account Settings
- Logout

3. DASHBOARD OVERVIEW
Welcome section:
- "Welcome back, [Name]!"
- Account status/tier if loyalty program

Quick Stats:
- Total orders
- Loyalty points (if applicable)
- Items in wishlist

Recent Orders (3 most recent):
- Order number, date, status, total
- "View Order" link
- "View All Orders" link

Saved Items:
- 3-4 wishlist items
- Quick "Add to Cart" button
- "View Wishlist" link

4. ORDERS PAGE
Order list:
- Order number (clickable)
- Order date
- Status badge (Processing, Shipped, Delivered)
- Total
- "Track" / "View" / "Reorder" buttons

Filters:
- Date range
- Status filter

Order Detail Page:
- Order number and date
- Status timeline/tracker
- Shipping address
- Payment method
- Items ordered with images
- Order summary
- "Track Package" button
- "Return Item" button
- "Download Invoice" link
- "Need Help?" link

5. ADDRESSES PAGE
Saved addresses:
- Card for each address
- Name and full address
- "Default" badge
- Edit / Delete buttons
- "Set as Default" link

"Add New Address" button
Form: Name, address fields, phone, default checkbox

6. PAYMENT METHODS
Saved cards:
- Card type icon
- Last 4 digits
- Expiry date
- "Default" badge
- Delete button

"Add Payment Method" button

7. WISHLIST PAGE
Grid of saved items:
- Product image
- Product name and price
- "Add to Cart" button
- "Remove" button
- Availability status
- Price drop alert toggle

Empty state:
- "Your wishlist is empty"
- "Start Shopping" button

8. ACCOUNT SETTINGS
Profile Information:
- Name
- Email
- Phone
- Birthday (for rewards)
- Profile photo

Password:
- Current password
- New password
- Confirm password

Preferences:
- Email notifications
- SMS notifications
- Newsletter subscription

Delete Account option (with confirmation)

Design: Clean, easy navigation. Quick access to common actions. Mobile-friendly.

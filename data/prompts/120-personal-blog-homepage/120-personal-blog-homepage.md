Create a personal blog homepage:

1. HEADER
- Blog name/logo (left)
- Navigation: Home, About, Categories, Archive, Contact
- Search icon
- Dark/Light mode toggle
- Subscribe button

2. HERO SECTION
Option A - Featured post:
- Large featured post card
- Featured image (full-width)
- Category tag
- Title (large)
- Excerpt
- Author with avatar, date, read time

Option B - Personal intro:
- Author photo
- Welcome message
- Brief bio
- Latest post below

3. RECENT POSTS SECTION
- "Latest Articles" heading
- Grid of 6 posts (3 columns desktop)
- Each post card:
  - Featured image
  - Category tag
  - Title
  - Excerpt (2 lines)
  - Author, date, read time
  - Read more link

4. CATEGORY SECTION
- "Browse by Topic" heading
- Category cards or tags:
  - Technology
  - Design
  - Life
  - Travel
  - Tutorials
- Post count per category

5. NEWSLETTER SECTION
- "Subscribe to my newsletter"
- "Get weekly updates on new posts"
- Email input + Subscribe button
- Privacy note
- Subscriber count (optional)

6. POPULAR/TRENDING
- "Most Read" sidebar or section
- List of 5 popular posts
- Numbered list with titles

7. ABOUT SIDEBAR (optional)
- Author photo
- Short bio
- Social links
- "Read more about me"

8. FOOTER
- Navigation links
- Social media icons
- Copyright
- "Built with [platform]"

Design: Clean, readable. Focus on typography. Good whitespace. Light theme with option for dark.

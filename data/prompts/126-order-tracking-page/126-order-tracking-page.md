Create an order tracking page:

1. TRACKING LOOKUP (public page)
For non-logged-in users:
- Order number input
- Email address input
- "Track Order" button

2. TRACKING RESULTS
Order Header:
- Order number
- Order date
- Estimated delivery date
- Carrier name and tracking number

3. TRACKING TIMELINE (vertical)
Status steps:
- Order Placed (date, time) ✓
- Order Confirmed ✓
- Shipped ✓
- In Transit (current)
- Out for Delivery
- Delivered

Each step shows:
- Status name
- Date and time
- Location (if applicable)
- Completed checkmark or pending dot

Current status highlighted:
- Larger icon
- Description of current state
- "Your package is on its way!"

4. DETAILED TRACKING HISTORY
Expandable section:
- Full tracking events list
- Date, time, location, status
- Latest events at top

5. DELIVERY INFORMATION
- Delivery address
- Delivery instructions
- Carrier contact

Actions:
- "Update Delivery Preferences"
- "Leave with neighbor" option
- "Hold at location" option

6. ORDER CONTENTS
Mini order summary:
- Item thumbnails
- Item names
- Quantities

7. MAP TRACKING (optional)
- Map showing package location
- Route visualization
- Estimated delivery window

8. NOTIFICATIONS
- "Get SMS updates" toggle
- "Email notifications" toggle
- Push notification opt-in

9. HELP SECTION
- "Package not arrived?"
- "Wrong item delivered?"
- "Contact Support" button
- FAQ links

10. MULTIPLE SHIPMENTS
If order split:
- Shipment 1 of 2
- Toggle between shipments
- Each with own tracking

Design: Clear timeline, prominent status. Mobile-friendly. Real-time updates if possible.

Create a changelog/release notes page for a SaaS product:

1. HEADER
- "What's New"
- "Stay up to date with the latest features and improvements"
- Subscribe to updates (email input)
- Filter by: All, Features, Improvements, Fixes

2. TIMELINE LAYOUT
Each release entry:
- Version number badge (v2.4.0)
- Release date
- Release type tag (Major Release / Minor Update / Patch)
- Title
- Description
- List of changes with icons:
  - ✨ New feature
  - 🚀 Improvement
  - 🐛 Bug fix
  - ⚠️ Breaking change

3. SAMPLE ENTRIES

ENTRY 1 (Latest):
v2.4.0 - January 15, 2025
"Dashboard 2.0 & Advanced Analytics"
Major Release

✨ New Features:
- Completely redesigned dashboard with customizable widgets
- Advanced analytics with custom date ranges
- New Gantt chart view for project timelines
- Dark mode support

🚀 Improvements:
- 50% faster page load times
- Improved search with filters
- Better mobile responsiveness

🐛 Bug Fixes:
- Fixed notification delivery delays
- Resolved calendar sync issues

ENTRY 2:
v2.3.2 - January 8, 2025
"Performance & Polish"
Patch

(Continue with 2-3 more entries)

4. PAGINATION
- "Load more" button or infinite scroll
- Or traditional pagination

5. SIDEBAR (optional)
- Quick links to major releases
- Categories/tags
- RSS feed link

Design: Clean timeline layout, good use of whitespace, version badges should be prominent.

Create custom error pages for a SaaS application:

1. 404 PAGE (Page Not Found)
Layout:
- Centered content
- Illustration or graphic (lost astronaut, broken link, etc.)
- "404" large text
- "Page not found"
- "The page you're looking for doesn't exist or has been moved."

Actions:
- "Go to Dashboard" primary button
- "Go Home" secondary button
- Search bar: "Try searching for what you need"

Helpful links:
- Documentation
- Help Center
- Contact Support

2. 500 PAGE (Server Error)
- "Something went wrong"
- "We're experiencing technical difficulties. Our team has been notified."
- "Try again" button
- "Check system status" link
- Error reference ID (for support)

3. 403 PAGE (Access Denied)
- "Access Denied"
- "You don't have permission to view this page."
- "Request access" button (sends request to admin)
- "Go back" link
- Contact admin option

4. MAINTENANCE PAGE
- "We'll be right back"
- "We're performing scheduled maintenance to improve your experience."
- Expected completion time
- Progress bar (if applicable)
- "Get notified when we're back" email input
- Social media links for updates

5. OFFLINE PAGE (for PWA)
- "You're offline"
- "Check your internet connection and try again."
- "Retry" button
- Show cached content if available

Design considerations:
- Keep branding consistent
- Use friendly, helpful language
- Always provide a way back to working pages
- Include support contact for critical errors
- Make illustrations/graphics on-brand

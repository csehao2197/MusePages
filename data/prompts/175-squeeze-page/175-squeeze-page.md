Create a squeeze page for maximum email capture:

1. HERO (ONLY SECTION)
Single-screen focus:
- Compelling headline
- One sentence of value
- Email input field
- Submit button
- No navigation

2. HEADLINE FORMULA
Use power patterns:
- "Get [Desirable Outcome] in [Timeframe]"
- "Free: [Valuable Resource]"
- "The [Adjective] Way to [Achieve Goal]"
- Question that resonates

3. VALUE STATEMENT
One line that sells:
- What they'll get
- How it helps them
- Why it's valuable
- Specificity wins

4. EMAIL FORM
Minimum friction:
- Single email field
- Or email + first name max
- Large input field
- Contrasting button color
- Action-oriented button text

5. BUTTON TEXT OPTIONS
- "Get Instant Access"
- "Send Me the [Resource]"
- "Yes, I Want This!"
- "Download Now"
- "Claim Your Free [X]"

6. MICRO-COMMITMENT
Below form:
- "We respect your privacy"
- "Unsubscribe anytime"
- "No spam, ever"
- Privacy policy link (small)

7. OPTIONAL ENHANCERS
Use sparingly:
- Resource preview image
- Bullet points (3 max)
- Single testimonial
- Download count
- Star rating

8. BACKGROUND DESIGN
- Solid color or subtle gradient
- Optional: relevant image
- High contrast text
- Minimal visual noise
- Focus on center

9. MOBILE LAYOUT
- Full-width form
- Large tap targets
- Readable without zoom
- Fast loading
- No horizontal scroll

10. EXIT INTENT
Optional popup:
- Appears on mouse exit
- Different angle/offer
- Last chance message
- Easy to close

Technical notes:
- No external links
- No navigation bar
- No footer links
- No social media
- Single purpose only

Conversion tips:
- Test headline variations
- Test button colors
- Test form field count
- Test button copy
- Track scroll depth

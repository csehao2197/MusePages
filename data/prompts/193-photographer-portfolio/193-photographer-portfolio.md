Create a photography portfolio website:

1. DESIGN PRINCIPLES
- Images are the hero - minimal UI
- Full-bleed images where possible
- White or very dark background
- Minimal text, let photos speak
- Smooth transitions between images

2. HOMEPAGE OPTIONS

Option A - Full-screen slideshow:
- Auto-advancing hero images
- Photographer name overlay
- Subtle navigation dots
- "Enter" or scroll to continue

Option B - Grid masonry:
- Masonry layout of best work
- Mixed sizes for visual interest
- Hover to see category/title
- Click to open gallery

3. NAVIGATION
- Minimal fixed header
- Logo/name left
- Categories: Portrait | Landscape | Commercial | Personal
- Contact link
- Hamburger on mobile

4. GALLERY PAGES
Category page layout:
- Hero image for category
- Masonry grid below
- Infinite scroll or load more
- Filter by subcategory

Individual photo view:
- Full-screen lightbox
- Arrow navigation
- Image info (camera, settings) on toggle
- Download/Purchase option if selling
- Close button

5. ABOUT PAGE
- Large portrait photo
- Bio story (not just resume)
- Client logos (if commercial work)
- Awards/publications
- Equipment list (photographers love this)
- Personal philosophy on photography

6. SERVICES PAGE (if commercial)
- Types of shoots offered
- Starting prices or "Contact for quote"
- What's included
- Sample packages
- Booking calendar or inquiry form

7. CONTACT PAGE
- Inquiry form
  - Name, email
  - Type of shoot (dropdown)
  - Preferred date
  - Message
- Contact info
- Studio location with map (if applicable)
- Response time

8. TECHNICAL REQUIREMENTS
- Fast image loading (lazy load, progressive JPEGs)
- Image optimization
- Responsive images (srcset)
- Touch-friendly gallery on mobile
- Social sharing for individual photos

Design: Timeless, not trendy. The photos should be the star. Consider a horizontal scrolling option for certain galleries.

Create a magazine-style publication blog:

1. HOMEPAGE LAYOUT
Hero zone:
- Feature story (full-width, dramatic)
  - Large image
  - Category
  - Headline
  - Author
- Secondary features (2-3 smaller)

Section 1:
- Section name: "Technology"
- 4 posts in grid
- "See all" link

Section 2:
- Section name: "Culture"
- List layout
- Thumbnails left, content right

Section 3:
- Section name: "Opinion"
- Author-focused cards

2. ARTICLE PAGE
Dramatic header:
- Full-bleed hero image
- Overlay with title
- Or title above image

Article meta:
- Section/Category
- Author with photo
- Date
- Estimated read time
- Share buttons

Content:
- Drop cap on first paragraph
- Pull quotes (styled)
- Full-width images
- Image captions
- Author asides

Article footer:
- Author bio box
- Tags
- Related from same section

3. SECTION PAGES
- Section hero/feature
- Section description
- Latest in section
- Editors' picks
- Infinite scroll or pagination

4. SPECIAL FEATURES
- Cover stories (special design)
- Photo essays (image-heavy layout)
- Long-form (chapter navigation)
- Data stories (with charts)
- Interviews (Q&A format)

5. NAVIGATION
Main nav:
- Sections (News, Tech, Culture, Opinion)
- Topics dropdown
- Search
- Subscribe button

Mobile:
- Hamburger menu
- Section tabs

6. AUTHORS PAGE
- Team page with all writers
- Each author: photo, name, title, post count
- Click for author profile

7. NEWSLETTER INTEGRATION
- Pop-up after scroll
- In-article signup
- Dedicated subscribe page
- Multiple newsletters by topic

8. ADVERTISING/MONETIZATION
- Banner positions
- In-content ads
- Sponsored content labels
- Membership/Paywall

Design: Editorial, polished. Mix of layouts for visual interest. Typography is key. Dense but organized.

Create an integrations/app marketplace page:

1. HEADER
- "Integrations"
- "Connect TaskFlow with your favorite tools"
- Search bar for integrations
- "Request an integration" link

2. FILTER SIDEBAR
Categories (with counts):
- All Integrations (45)
- Communication (12)
- Development (8)
- File Storage (6)
- Calendar (5)
- Analytics (7)
- Marketing (4)
- Other (3)

Filter by:
- Free / Premium
- Official / Community
- Most Popular / Newest

3. INTEGRATION GRID
Each card shows:
- App logo (64x64)
- App name
- Category tag
- Short description (1 line)
- "Official" or "Community" badge
- Install count or rating
- "Connect" or "Installed" button

4. FEATURED INTEGRATIONS (top section)
- Highlight 3-4 popular integrations
- Larger cards with more detail

5. INTEGRATION DETAIL PAGE
When clicking an integration:
- Large logo and name
- Full description
- Screenshots of the integration
- Features list
- Setup instructions
- Requirements
- "Connect" button
- User reviews/ratings
- Related integrations

6. SAMPLE INTEGRATIONS TO INCLUDE
- Slack: Get notifications in Slack channels
- GitHub: Link commits and PRs to tasks
- Google Drive: Attach files from Drive
- Zapier: Connect to 3000+ apps
- Figma: Embed designs in tasks
- Jira: Sync issues bidirectionally
- Zoom: Schedule meetings from tasks
- Notion: Import/export to Notion

Design: Grid layout, consistent card sizes, good visual hierarchy with logos.

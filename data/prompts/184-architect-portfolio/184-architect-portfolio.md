Create a portfolio for an architect or architecture firm:

1. HOMEPAGE
- Full-screen project image or video
- Firm/architect name
- Tagline: "Architecture for human experience"
- Minimal navigation
- Scroll to reveal projects
- Featured project with large imagery

2. PROJECTS PAGE
Categories:
- All Projects
- Residential
- Commercial
- Cultural
- Hospitality
- Urban Design
- Interiors

Project grid:
- Large thumbnails (architecture needs big images)
- Project name and location
- Year completed
- Click to view full project

3. PROJECT CASE STUDY
Essential content:
- Hero image (exterior shot)
- Project name and location
- Year, size (sq ft/m), budget range
- Project type
- Status: Completed / Under Construction / Concept

Sections:
- Overview (project description)
- Site context (location, surroundings)
- Design concept (the big idea)
- Image gallery:
  - Exterior photos
  - Interior photos
  - Site photos
  - Night shots
- Drawings:
  - Site plan
  - Floor plans
  - Sections
  - Elevations
- Renders (if concept/in progress)
- Construction photos
- Credits (team, photographers, contractors)

4. ABOUT/STUDIO PAGE
- Firm philosophy
- Team members (photos, roles, bios)
- Office photos
- History/timeline
- Awards and recognition
- Publications featuring the work

5. SERVICES PAGE
- Architectural Design
- Interior Design
- Master Planning
- Feasibility Studies
- Project Management
- Process overview with phases

6. NEWS/JOURNAL
- Project completions
- Awards won
- Media features
- Lectures and exhibitions

7. CONTACT
- Office address with map
- Email
- Phone
- Social links (Instagram is big for architecture)
- Project inquiry form
- Careers link

Design: Clean, minimal, let the architecture speak. White backgrounds work well. Grid-based layout reflecting architectural precision. High-quality photography is essential.

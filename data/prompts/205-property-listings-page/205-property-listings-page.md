Create a property listings page for a real estate platform called "HomeHub". Include these features:

1. SEARCH HEADER
- Location search with autocomplete
- Buy/Rent/Sold toggle
- Save search button
- Share search link

2. FILTER PANEL (Collapsible Sidebar or Top Bar)
- Price Range: Min/Max inputs or dual slider
- Beds: Any, 1+, 2+, 3+, 4+, 5+
- Baths: Any, 1+, 2+, 3+
- Property Type: Checkboxes (House, Condo, Townhouse, Multi-family, Land)
- Square Feet: Min/Max
- Lot Size: Min/Max
- Year Built: Range slider
- Days on Market: Any, <7, <14, <30
- Keywords: Pool, Garage, Waterfront, etc.
- HOA: Yes/No/Any
- Parking Spaces
- "More Filters" expandable
- Clear All / Apply Filters buttons
- Active filter count badge

3. RESULTS HEADER
- Results count: "156 homes for sale in [Location]"
- Sort by: Newest, Price (Low-High), Price (High-Low), Beds, Sq Ft
- View toggle: Grid / List / Map

4. MAP VIEW (Split Screen Option)
- Interactive map with property markers
- Price shown on markers
- Cluster for dense areas
- Map adjusts to current listings
- "Search as I move the map" toggle
- Draw custom search area tool

5. PROPERTY CARDS (Grid View)
- Main image with photo count
- Image carousel on hover
- Price (large)
- Address (street, city)
- Beds | Baths | Sq Ft
- Price per sq ft
- Lot size (if applicable)
- Status badge: Active, Pending, Contingent
- Days on market
- Heart icon to favorite
- Schedule tour button

6. PROPERTY CARDS (List View)
- Larger image
- Full property description preview
- More details visible
- Quick action buttons

7. PAGINATION / INFINITE SCROLL
- Load more button or infinite scroll
- Page numbers with navigation
- Results per page selector

8. NO RESULTS STATE
- Friendly message
- Suggestions to broaden search
- Create alert for new matches

9. SAVED SEARCH / ALERTS
- Save current search criteria
- Email alert frequency options
- Manage saved searches

Design: Clean, functional with lots of whitespace. Primary: Teal (#0D9488). Easy-to-scan cards. Fast-loading images with lazy loading. Mobile: Full-width cards, collapsible filters, sticky map toggle.

Create a minimal portfolio website for a UI/UX designer:

1. OVERALL STYLE
- Dark theme (#0a0a0a background)
- Minimal, lots of whitespace
- Smooth scroll animations
- Accent color: subtle white or single brand color
- Typography: Clean sans-serif (Inter or similar)

2. HERO SECTION
- Full viewport height
- Large name/logo (animated text reveal)
- One-line tagline: "UI/UX Designer crafting digital experiences"
- Subtle scroll indicator at bottom
- Optional: Abstract geometric background animation

3. ABOUT SECTION
- Professional photo (with subtle hover effect)
- Brief bio (3-4 sentences max)
- Current status: "Available for freelance"
- Location with timezone
- Download resume link

4. WORK/PROJECTS SECTION
Grid layout (2 columns on desktop):
- Each project: Large thumbnail image
- Project title (appears on hover)
- Category tag (App Design, Web Design, Branding)
- Hover effect: Image scales up, overlay with "View Project"
- Click opens project detail page

5. PROJECT DETAIL PAGE
- Full-width hero image
- Project title and year
- Role and duration
- Client name
- Challenge/Solution/Result sections
- Image gallery with lightbox
- Next/Previous project navigation

6. SKILLS SECTION
- Simple list or tag cloud
- Categories: Design (Figma, Sketch), Prototyping (Framer, Principle), Research (User Testing, Analytics)
- No progress bars (they're meaningless)

7. CONTACT SECTION
- "Let's work together"
- Email link (mailto:)
- Social links (LinkedIn, Dribbble, Twitter)
- Optional: Simple contact form

8. FOOTER
- Copyright
- "Designed and built by [Name]"

Animations: Use subtle fade-ins and slide-ups on scroll. Keep it elegant, not flashy.

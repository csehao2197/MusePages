Create a portfolio for a freelance creative professional:

1. HOMEPAGE
- Memorable headline: "I design brands that people remember"
- Showreel or hero image carousel
- Brief intro (who you are, what you do)
- Selected work preview (3-4 projects)
- Testimonial snippet
- CTA: "Start a Project"

2. WORK PAGE
Filter by category:
- All
- Branding
- Web Design
- Print
- Motion

Project grid:
- Thumbnail image
- Project title
- Client name
- Year
- Hover: Brief description + "View Project"

3. PROJECT CASE STUDY TEMPLATE
Structure:
- Hero image (full-width)
- Project overview
  - Client
  - Services provided
  - Year
  - Collaborators
- The Challenge (what problem needed solving)
- The Process (research, concepts, iterations)
  - Include sketches, wireframes, early concepts
- The Solution (final deliverables)
  - Full-width image galleries
  - Before/after if applicable
- The Results (metrics, testimonials)
- Next project link

4. ABOUT PAGE
- Professional photo
- Story-driven bio (why you do what you do)
- Services offered with brief descriptions
- Process overview (4-5 steps)
- Clients worked with (logo grid)
- Press/features
- Personal interests (makes you human)

5. SERVICES PAGE
For each service:
- Service name
- What's included
- Starting price or "From $X"
- Typical timeline
- "Inquire" button

Services might include:
- Brand Identity
- Website Design
- Social Media Design
- Print Collateral
- Packaging Design

6. TESTIMONIALS/REVIEWS
- Client photo
- Quote
- Name, title, company
- Project linked
- Display as carousel or grid

7. BLOG/JOURNAL (optional)
- Behind-the-scenes posts
- Design tips
- Industry thoughts
- Builds authority and SEO

8. CONTACT PAGE
- "Let's create something together"
- Project inquiry form
  - Name, email, company
  - Budget range (dropdown)
  - Timeline
  - Project type
  - Project description
- Calendar booking embed (Calendly)
- FAQ about working together

Design: Should reflect your personal brand. Use your own work as decoration. Show personality through copywriting.

Create a PPC ad landing page optimized for paid traffic:

1. ABOVE THE FOLD
Message match with ad:
- Headline mirrors ad copy
- Same offer/promotion
- Consistent visuals
- Immediate value proposition
- Single focused CTA

2. TRUST SIGNALS
Instant credibility:
- Brand logo prominent
- Security badges
- Customer logos
- Review ratings
- "As seen in" mentions

3. HERO SECTION
- Headline matching ad keyword
- Subheadline with benefit
- Hero image/video of product
- Primary CTA button
- Optional: phone number for calls

4. VALUE PROPOSITION
Quick-scan benefits:
- 3-4 key benefits
- Icon + short text format
- What makes you different
- Why choose you over competitors

5. SOCIAL PROOF
Build trust fast:
- Star ratings display
- Number of customers
- Testimonial carousel
- Trust badges
- Money-back guarantee

6. OFFER DETAILS
Clear and compelling:
- What they get
- Price/discount if applicable
- Limited time urgency
- Bonus items included
- Risk reversal (guarantee)

7. SINGLE FORM
Minimize friction:
- Essential fields only
- Name and email minimum
- Phone optional
- Clear privacy statement
- Strong submit button text

8. FAQ (OBJECTION HANDLING)
- Address common concerns
- Shipping/delivery info
- Return policy
- Support availability
- Payment security

9. URGENCY ELEMENTS
- Countdown timer
- Limited availability
- "X people viewing"
- Stock/seats remaining
- Offer expiration

10. MOBILE OPTIMIZATION
- Sticky CTA button
- Click-to-call
- Fast load time
- Thumb-friendly buttons
- Simplified form

11. TRACKING
- UTM parameter capture
- Conversion pixel placement
- Form submission tracking
- Heat map ready

Design notes:
- No navigation menu (reduce exits)
- Single conversion goal
- Load time under 3 seconds
- Mobile-first design
- A/B test headline and CTA

Color psychology:
- Use contrasting CTA color
- Trust-building blues/greens
- Urgency reds/oranges sparingly
